# Kidou — Idées de fonctionnalités post-MVP

> Fonctionnalités à considérer après le MVP.

---

## Quick wins (polish)

| Idée | Description |
|------|-------------|
| **Compteur projets visible** | Afficher "2/3 projets" sur le dashboard |
| **Share button** | Copier l'URL publique en un clic avec toast de confirmation |
| **Favicon dynamique** | Badge de progression sur l'icône du navigateur |

---

## Engagement & social

| Idée | Description |
|------|-------------|
| **Changelog automatique** | Générer un résumé des milestones complétées cette semaine pour poster sur Twitter/LinkedIn |
| **Embed widget** | `<iframe>` ou image dynamique à intégrer dans un README GitHub |
| **Streak counter** | "5 jours consécutifs de progression" |

---

## Productivité

| Idée | Description |
|------|-------------|
| **Notes par milestone** | Ajouter des détails/blockers sur chaque milestone |
| **Sous-milestones** | Décomposer une milestone en tâches plus petites |
| **Import GitHub Issues** | Parser les issues d'un repo comme milestones |
| **Archive projets** | Garder l'historique sans compter vers la limite de 3 |
